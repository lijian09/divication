# 灵谕 — UI/UX 设计规范文档

> **版本**：v1.0
> **基于原型**：prototype.md v1.0
> **设计目标**：微信小程序（Taro 3.x + React 18）
> **目标用户**：18~35 岁，对神秘学/情绪消费感兴趣的年轻人

---

## 1. 设计理念

### 1.1 情绪关键词

| 关键词 | 设计表达 |
|--------|----------|
| **神秘** | 深邃的紫蓝渐变背景、星空粒子、朦胧光晕 |
| **温暖** | 金色高亮点缀、圆润的卡片边角、柔和的阴影 |
| **被理解** | 亲切的中文排版、舒适的行高、留白充足的呼吸感 |
| **仪式感** | 翻牌 3D 动画、洗牌手势交互、流式文字揭晓 |
| **专业感** | 统一的色彩系统、严谨的排版层级、清晰的信息架构 |

### 1.2 视觉隐喻

- **星空**：背景中散布的微小光点粒子，象征命运的无限可能性
- **月光**：主色调的深紫偏蓝，如月夜天幕，营造宁静冥想氛围
- **能量流动**：金色渐变从按钮、边框到牌面光晕，贯穿整个产品，象征能量的指引
- **翻开真相**：卡牌从背面到正面的 3D 翻转，隐喻"看见命运"的仪式瞬间
- **水滴涟漪**：按钮点击时的微扩散反馈，如投入命运之水的涟漪

### 1.3 设计原则

1. **沉浸优先**：深色背景减少视觉干扰，让用户聚焦于牌面和解读内容，打造"只有你和牌"的沉浸体验
2. **金色引导**：所有可操作元素（按钮、选中态、高亮文字）统一用金色传达，用户不需思考"哪里能点"
3. **节奏感设计**：信息分层递进，从品牌区到运势到行动按钮，符合用户"先感受氛围、再了解内容、最后行动"的心理节奏
4. **仪式感注入**：每个交互节点（洗牌、选牌、翻牌、解读揭晓）都有精心设计的动效，让 AI 产品也有"命运降临"的庄重感
5. **情绪安全**：错误态用温和的文案和插画而非冰冷的系统提示；免责信息用灰色小字不破坏氛围，但始终可见

## 3. 字体系统

### 3.1 字体指定

| 字体类型 | 指定字体 | Fallback 链 | 说明 |
|----------|----------|-------------|------|
| 中文 | **PingFang SC** (iOS) / **Noto Sans SC** (Android) | `Microsoft YaHei`, `sans-serif` | 微信小程序内优先使用系统字体 |
| 英文/数字 | **DIN Pro** | `SF Pro Text`, `Helvetica Neue`, `sans-serif` | 价格和数字使用 DIN Pro 增强高级感 |
| 品牌字体 | **自定义字体**（灵谕 Logo） | - | 仅品牌 Logo 区域使用，需嵌入小程序 |

> **注意**：微信小程序不支持 `@font-face` 加载远程字体（除微信官方字体），品牌字体需预置为图片或 SVG。DIN Pro 可通过 Base64 内嵌（仅含数字和常见符号，控制在 50KB 以内）。

### 3.2 字号层级表

| 层级 | 字号 | 行高 | 字重 | 字间距 | 用途 |
|------|------|------|------|--------|------|
| H1 | 24px | 36px | Bold (700) | 0.5px | 页面大标题（"遇见你的塔罗师"） |
| H2 | 20px | 30px | SemiBold (600) | 0.3px | 卡片区标题（"今日运势"、"选择问题"） |
| H3 | 16px | 24px | SemiBold (600) | 0.2px | 列表项标题、按钮文字 |
| Body | 14px | 22px | Regular (400) | 0 | 正文、解读内容、卡片描述 |
| Caption | 12px | 18px | Regular (400) | 0 | 辅助文字、时间戳、免责小字 |
| Micro | 10px | 16px | Regular (400) | 0 | 标签、角标、版本号 |
| Price | 24px | 36px | Bold (700) | 0 | 价格数字（使用 DIN Pro） |
| Quota | 36px | 48px | Bold (700) | 0 | 配额大数字（使用 DIN Pro） |

### 3.3 行高与字重规范

- **行高**：正文统一 1.5 倍行高（14px x 1.5 = 21px，取整 22px），确保中文阅读舒适度
- **字重**：仅使用三个档位 — Regular (400)、SemiBold (600)、Bold (700)
- **字间距**：标题微调字间距（0.2~0.5px）增强大气感，正文不做字间距调整
- **文本溢出**：
  - 单行截断：`overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`
  - 两行截断：`-webkit-line-clamp: 2; -webkit-box-orient: vertical; display: -webkit-box;`

## 5. 组件设计规范

### 5.1 按钮

#### 主按钮（PrimaryButton）
- **尺寸**：全宽 - 40px（即左右各 20px 内边距）x 48px
- **圆角**：24px（胶囊形）
- **背景**：`linear-gradient(135deg, #F0D68A 0%, #D4A843 100%)`
- **文字**：16px SemiBold，颜色 `#1A0A2E`（深色文字在金色背景上）
- **状态**：
  - 默认：正常渐变
  - 按下：整体缩小至 `scale(0.97)`，0.1s ease，同时渐变加深 10%
  - 禁用：渐变变灰 `#555` → `#444`，文字 `rgba(255,255,255,0.3)`，`pointer-events: none`
  - 加载：渐变正常，文字替换为 Loading Spinner（居中旋转 16x16px），按钮不可点击

#### 次要按钮（SecondaryButton）
- **尺寸**：全宽 - 40px x 40px
- **圆角**：20px
- **背景**：`transparent`
- **边框**：1px solid `rgba(212, 168, 67, 0.5)`
- **文字**：14px SemiBold，颜色 `#D4A843`
- **状态**：
  - 默认：如上
  - 按下：背景 `rgba(212, 168, 67, 0.1)`，边框 `#D4A843`
  - 禁用：边框 `rgba(255,255,255,0.15)`，文字 `rgba(255,255,255,0.2)`

#### 文字按钮（TextButton）
- **尺寸**：自适应宽度 x 36px
- **背景**：`transparent`，无边框
- **文字**：14px Regular，颜色 `#A8A3B8`
- **按下态**：文字颜色变 `#FFFFFF`，0.15s 过渡

#### 幽灵按钮（GhostButton）- 底部"下次再说"类
- **尺寸**：自适应宽度 x 36px
- **背景**：`transparent`
- **文字**：12px Regular，颜色 `#6B6580`，带下划线
- **按下态**：颜色变 `#A8A3B8`

### 5.2 卡牌组件（TarotCard）

#### 牌背
- **尺寸-小**：60 x 96px（洗牌密集排列）
- **尺寸-中**：80 x 128px（选牌阶段、解读区卡槽）
- **尺寸-大**：100 x 160px（翻牌阶段、三牌阵结果）
- **尺寸-展示**：200 x 320px（单牌结果页）
- **圆角**：8px（小/中）、12px（大/展示）
- **牌背样式**：深紫渐变底 + 中央灵谕品牌星形图腾 + 细密边框纹理
- **阴影**：`0 2px 8px rgba(0,0,0,0.4)`（小/中）、`0 4px 16px rgba(0,0,0,0.5)`（大/展示）

#### 牌面
- **尺寸同牌背对应规格**
- **边框**：1px solid `rgba(212, 168, 67, 0.3)`（大尺寸时）
- **内容区**：牌面图案 + 底部牌名 + 正/逆位标签

#### 牌面翻转态
- **实现方式**：CSS 3D transform，`perspective: 800px`，父子容器 `preserve-3d`
- **正面/背面**：`backface-visibility: hidden`，正面初始 `rotateY(180deg)`
- **翻转动画**：`transform: rotateY(0deg)` → `rotateY(180deg)`，0.6s ease-out
- **光影效果**：翻转过程中，牌面中心有一道从左到右扫过的金色高光（使用 `::after` 伪元素 + `opacity` 动画）

### 5.3 输入框

- **尺寸**：全宽 - 40px x 80px（多行）/ 48px（单行）
- **圆角**：12px
- **背景**：`rgba(255, 255, 255, 0.06)`
- **边框**：1px solid `rgba(255, 255, 255, 0.15)`
- **文字**：14px Regular，颜色 `#FFFFFF`
- **Placeholder**：颜色 `#A8A3B8`
- **状态**：
  - 默认：如上
  - 聚焦：边框 `1px solid #D4A843`，背景不变
  - 错误（敏感词/超限）：边框 `1px solid #E53935`，底部出现红色提示文字
  - 禁用：背景 `rgba(255,255,255,0.03)`，文字 `rgba(255,255,255,0.3)`

### 5.4 选项卡（问题分类选择）

- **尺寸**：80 x 80px
- **圆角**：12px
- **背景**：`rgba(255, 255, 255, 0.06)`
- **边框**：1px solid `rgba(255, 255, 255, 0.1)`
- **内部布局**：图标 32x32px 居上 + 文字 12px 居下，间距 8px
- **状态**：
  - 默认：如上
  - 选中：边框 `2px solid #D4A843`，背景 `rgba(212, 168, 67, 0.08)`，图标高亮为金色
  - 按下：`scale(0.95)`，0.1s

### 5.5 弹窗

#### 免责协议弹窗
- **蒙层**：`rgba(0, 0, 0, 0.6)`，不可穿透
- **容器**：80% 屏宽 x 80% 屏高，白色背景 `#FFFFFF`，圆角 16px
- **内边距**：24px
- **标题**：20px SemiBold，颜色 `#1A0A2E`，居中
- **内容区**：高度 400px，可滚动，14px Regular，颜色 `#333333`，行高 22px
- **同意按钮**：全宽 - 48px x 48px，圆角 24px，同主按钮样式，滚动到底前 `opacity: 0.4` + `pointer-events: none`
- **不同意按钮**：文字按钮，14px，颜色 `#999999`，居中于同意按钮下方

#### 付费引导弹窗
- **容器**：85% 屏宽，`#1A0A2E` 背景（深色主题弹窗），圆角 16px
- **阴影**：`0 8px 32px rgba(0,0,0,0.6)`
- **套餐卡片**：紧凑版，全宽 - 32px x 72px，`rgba(255,255,255,0.06)` 背景
- **选中态**：2px solid `#D4A843`
- **购买按钮**：主按钮样式
- **关闭按钮**：文字按钮"下次再说"

### 5.6 Loading 动画

- **星形图标**：60 x 60px，金色 `#D4A843`
- **动画**：`rotate(360deg)`，1.2s linear 无限循环
- **背景**：透明或半透明卡片背景
- **配套文字**：14px `#A8A3B8`，居中于 spinner 下方

### 5.7 Toast 提示

- **位置**：屏幕垂直居中
- **背景**：`rgba(0, 0, 0, 0.8)`
- **圆角**：8px
- **内边距**：12px 24px
- **文字**：14px `#FFFFFF`，居中
- **图标**（可选）：成功 `#4CAF50` 对勾 / 错误 `#E53935` 叉号，24x24px，位于文字上方
- **显示时长**：2s 自动消失（成功/信息）/ 2.5s（错误）
- **动画**：淡入 0.2s ease-out，淡出 0.2s ease-in

### 5.8 TabBar

- **实现方式**：标准微信 TabBar（`custom: false`）+ PNG 图标
- **整体高度**：由微信控制（50px + 底部安全区）
- **背景**：`#0D1B3E`
- **Tab 数量**：3 个（首页、抽牌、我的）
- **图标**：81x81px PNG，线性风格
  - 默认态：灰色 `#6B6580`
  - 选中态：金色 `#D4A843`
- **图标文件**：`tab-home.png`、`tab-draw.png`、`tab-profile.png`（+ `-active` 后缀）

## 6. 牌面设计指南

### 6.1 牌面尺寸比例

- **宽:高 = 5:8**（标准塔罗牌比例）
- 具体尺寸：
  - 缩略图：40 x 64px（历史记录）
  - 小牌：60 x 96px（洗牌）
  - 中牌：80 x 128px（选牌、三牌阵结果）
  - 大牌：100 x 160px（翻牌）
  - 展示牌：200 x 320px（单牌结果）

### 6.2 牌背设计方向

- **统一背面**：所有 78 张牌共用一个牌背
- **设计元素**：
  - 底色：深紫渐变 `#2A1A4E` → `#1A0A2E`
  - 中央图腾：灵谕品牌星形符号，金色线条勾勒，尺寸约占牌面 40%
  - 边框：内嵌 2px 金色细框，距边缘 4px
  - 纹理：细密的星空微点散布，密度约 15% 面积
  - 四角：小五角星装饰

### 6.3 大阿尔卡纳（Major Arcana，22 张）视觉风格

- **艺术风格**：新艺术运动（Art Nouveau）+ 现代扁平插画的融合
- **色彩**：每张牌有专属主色调（如愚人牌-天蓝色、女祭司牌-银紫色），但统一在深色框架内
- **构图**：中央人物/象征物占据 60% 画面，留出上下空间给名称和编号
- **人物风格**：半写实插画，面部简约但有神秘感，不做过度写实
- **背景**：每张牌有独特的象征性背景（星空、山水、殿堂等），非纯色
- **编号**：罗马数字标注于牌面顶部中央
- **牌名**：中文名称标注于牌面底部，12px 金色

## 8. 动效设计规范

### 8.1 翻牌动画（3D 翻转）

| 参数 | 值 |
|------|-----|
| **触发条件** | 用户点击背面朝上的牌面 |
| **触发方式** | 点击 |
| **动画类型** | CSS 3D transform，`rotateY(180deg)` |
| **持续时间** | 600ms |
| **缓动曲线** | `ease-out` |
| **关键帧** | 0ms: `rotateY(0deg)` → 300ms: `rotateY(90deg)` → 600ms: `rotateY(180deg)` |
| **透视距离** | `perspective: 800px` |
| **光影效果** | 牌面中央有一道从左到右扫过的金色高光（0%~50% 宽度），在 200ms~400ms 间扫过 |
| **音效建议** | 可选：轻微的"翻页"音效 |
| **性能建议** | 使用 `will-change: transform`；牌面正反面使用 `backface-visibility: hidden`；图片预加载避免翻转时白屏 |

### 8.2 洗牌动画

| 参数 | 值 |
|------|-----|
| **触发条件** | 用户在牌堆区域上下滑动手势 |
| **触发方式** | touchmove 事件 |
| **动画类型** | 牌面 X/Y 轴随机位移 + 随机旋转 |
| **持续时间** | 持续手势触发；每组牌的动画 300ms |
| **缓动曲线** | `ease-in-out` |
| **位移范围** | X 轴 ±20px，Y 轴 ±20px |
| **旋转范围** | ±15 度 |
| **手势映射** | 滑动距离映射到牌堆的偏移量，上滑牌堆向上偏移，下滑反之 |
| **进度回弹** | 松手后进度未满时，0.3s `ease-in` 回到 0 |
| **性能建议** | 使用 CSS `transform` 而非 `top/left`；限制同时动画的元素数量（仅可见区域内的牌参与动画）；使用 `requestAnimationFrame` 节流 |

### 8.3 星空/粒子背景动效

| 参数 | 值 |
|------|-----|
| **触发条件** | 页面加载后持续运行（仅首页和品牌区） |
| **粒子数量** | 15~25 个 |
| **粒子大小** | 1~3px 圆点 |
| **粒子颜色** | 白色，`opacity: 0.2 ~ 0.6` |
| **运动方式** | 缓慢漂浮，模拟星空微动 |
| **运动范围** | 全品牌区/全屏 |
| **移动速度** | X 轴 ±0.3px/帧，Y 轴 -0.1px/帧（缓慢上浮） |
| **闪烁效果** | 每个粒子独立的 opacity 脉动，周期 3~5s |
| **性能建议** | 使用 Canvas 绘制（而非多个 DOM 元素）；页面不可见时暂停（`visibilitychange` 监听）；粒子数量控制在 25 以内 |

### 8.4 AI 解读文字逐字输出效果

| 参数 | 值 |
|------|-----|
| **触发条件** | AI 流式接口返回文字片段 |
| **输出方式** | 逐字追加到 DOM |
| **间隔时间** | 每字 30ms（可通过接口返回的速度调节） |
| **光标** | 闪烁的竖线光标，0.5s 周期，紧跟最后一个字 |
| **滚动** | 新文字超出可视区域时自动平滑滚动到底部 |
| **性能建议** | 使用 `innerHTML` 拼接而非逐字创建 DOM 节点；长文本超过 2000 字时考虑虚拟滚动 |

### 8.5 页面转场动效

| 转场类型 | 动画 | 时长 | 缓动曲线 | 适用场景 |
|----------|------|------|----------|----------|
| 前进导航 | 新页面从右侧滑入，旧页面同时向左偏移 30% 并缩至 0.95 | 300ms | `ease-out` | 所有 navigateTo |
| 返回导航 | 当前页向右侧滑出，下层页面从左偏移 30% 恢复 | 250ms | `ease-in` | 所有 navigateBack |
| Tab 切换 | 淡入淡出 | 200ms | `linear` | TabBar 切换 |
| 弹窗出现 | 蒙层淡入 0.25s + 弹窗淡入+上移 20px→0 | 250ms | `ease-out` | 所有弹窗 |
| 弹窗消失 | 弹窗淡出+下移 0→20px + 蒙层淡出 | 200ms | `ease-in` | 所有弹窗关闭 |

### 8.6 选牌飞出动画

| 参数 | 值 |
|------|-----|
| **触发条件** | 用户点击选中一张牌 |
| **起始位置** | 牌堆中被点击的牌的位置 |
| **目标位置** | 底部解读区的对应卡槽 |
| **动画类型** | `translate` + `scale` + `opacity` |
| **持续时间** | 500ms |
| **缓动曲线** | `cubic-bezier(0.34, 1.56, 0.64, 1)`（弹性效果） |
| **缩放变化** | 从 1.0 缩小至 0.9 再回弹至 1.0 |
| **性能建议** | 使用 `transform` 属性，触发 GPU 加速 |

## 10. 适配与响应式

### 10.1 iPhone 安全区域处理

| 区域 | 处理方式 |
|------|----------|
| **顶部安全区**（刘海/灵动岛） | 使用 `wx.getSystemInfoSync().statusBarHeight` 获取状态栏高度；自定义导航栏高度固定 44px；内容区从 `statusBarHeight + 44px` 开始 |
| **底部安全区**（Home Indicator） | TabBar 底部 padding 设为 `env(safe-area-inset-bottom)` 或 `constant(safe-area-inset-bottom)`（兼容 iOS 11.0~11.2）；非 TabBar 页面的底部固定按钮同理 |
| **圆角屏幕** | 页面背景色统一 `#1A0A2E`，与屏幕圆角自然过渡；无需特殊处理 |

### 10.2 不同屏幕尺寸的适配策略

| 策略 | 具体实现 |
|------|----------|
| **宽度自适应** | 所有水平尺寸使用 `calc(100% - 40px)` 或 `rpx` 单位，基于 750rpx 设计稿 |
| **高度弹性** | 使用 `flex` 布局 + `scroll-view`，内容区自适应剩余高度 |
| **字号不缩放** | 文字使用固定 `px` 值，不随屏幕缩放 |
| **图片适配** | 牌面图片使用固定宽高比（5:8），通过 `aspect-ratio` 保持比例 |
| **小屏适配**（如 iPhone SE） | 减少品牌区高度（120px → 80px）；缩短运势卡片高度（160px → 140px）；确保核心 CTA 按钮可见 |
| **大屏适配**（如 iPhone Pro Max） | 卡片宽度不变（全宽-40px），内容不拉伸；牌堆区域可适当增加牌面数量 |

### 10.3 横屏处理

- **强制竖屏**：在 `app.json` 中设置 `"pageOrientation": "portrait"` 全局禁用横屏
- **原因**：塔罗牌交互（洗牌手势、翻牌动画）均为竖屏设计，横屏会破坏交互逻辑
- **处理方式**：如用户意外横屏，页面保持竖屏布局不变，两侧出现深色填充
