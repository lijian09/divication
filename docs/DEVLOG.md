## 操作类型说明

| 类型 | 含义 |
|------|------|
| `feat` | 新功能 |
| `fix` | Bug 修复 |
| `refactor` | 重构（不改变功能） |
| `style` | 样式/视觉调整 |
| `docs` | 文档更新 |
| `chore` | 工程配置/依赖/构建 |
| `test` | 测试相关 |
| `perf` | 性能优化 |
