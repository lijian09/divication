> **版本**：v1.0

> **设计规范**：微信小程序（Taro 3.x + React 18）

## 设计规范总览

### 色彩系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色-深紫 | `#1A0A2E` | 背景底色，神秘感 |
| 主色-深蓝 | `#0D1B3E` | 导航栏、卡片背景 |
| 强调色-金色 | `#D4A843` | 按钮、高亮、品牌元素 |
| 强调色-浅金 | `#F0D68A` | 次要强调、边框 |
| 文字-主 | `#FFFFFF` | 标题、正文（深色背景上） |
| 文字-辅 | `#A8A3B8` | 辅助说明、placeholder |
| 文字-注 | `#6B6580` | 免责声明、次要信息 |
| 背景-卡片 | `rgba(255,255,255,0.08)` | 半透明卡片 |
| 状态-成功 | `#4CAF50` | 支付成功等 |
| 状态-错误 | `#E53935` | 错误提示 |
| 状态-警告 | `#FF9800` | 次数不足等 |

### 字体层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| H1 | 24px | Bold | 页面大标题 |
| H2 | 20px | Bold | 卡片标题、区块标题 |
| H3 | 16px | SemiBold | 列表项标题、按钮文字 |
| Body | 14px | Regular | 正文、解读内容 |
| Caption | 12px | Regular | 辅助文字、时间戳 |
| Micro | 10px | Regular | 标签、角标 |

### 尺寸规范

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 状态栏 | 高度 44px（iOS）/ 24px（Android） | 系统占用 |
| 导航栏 | 高度 44px | 自定义导航栏 |
| 安全顶部 | 88px（iOS 标准） | 状态栏 + 导航栏 |
| TabBar | 高度 50px + 底部安全区 34px | iPhone 底部 |
| 单牌展示 | 200 x 320px | 结果页牌面 |
| 三牌阵-每张 | 100 x 160px | 三牌阵布局 |
| 牌背面 | 80 x 128px | 洗牌/选牌阶段 |
| 主按钮 | 高度 48px，圆角 24px | "开始占卜"等 |
| 次按钮 | 高度 40px，圆角 20px | "查看牌义"等 |
| 页面水平内边距 | 20px | 通用 |

### 动效规范

| 场景 | 动画类型 | 时长 | 缓动曲线 |
|------|----------|------|----------|
| 洗牌 | 牌面交错位移 + 旋转 | 持续手势触发，每组 0.3s | ease-in-out |
| 选牌飞出 | 从牌堆飞到解读区 | 0.5s | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 翻牌 | Y 轴 3D 旋转 180 度 | 0.6s | ease-out |
| 页面进入 | 从右侧滑入 | 0.3s | ease-out |
| 弹窗出现 | 淡入 + 上移 20px | 0.25s | ease-out |
| Tab 切换 | 淡入淡出 | 0.2s | linear |
| AI 文字逐字 | 逐字/逐句出现 | 每字 30ms | - |
| 加载指示 | 星形旋转 | 1.2s/圈 | linear |

**元素说明**：

| 元素 | 类型 | 尺寸/位置 | 交互说明 |
|------|------|-----------|----------|
| 品牌 Logo 区 | 容器 | 全宽 x 120px，距顶 88px | 静态展示，深紫到深蓝渐变背景 |
| 今日运势卡片 | 卡片 | 全宽-40px，高 160px | 点击跳转牌义详情页；左滑可切换 |
| 运势卡片-牌面 | 图片 | 80 x 128px，左侧 | 牌面缩略图 |
| 运势卡片-文字 | 文本 | 右侧区域 | 正位/逆位 + 关键词摘要 |
| 快捷分类入口 | 横向滚动 | 全宽 x 60px | 点击直接进入对应类别的问题选择页 |
| 次数提示条 | 文本条 | 全宽-40px x 36px | 显示剩余免费次数 |
| 开始占卜按钮 | 按钮 | 全宽-40px x 48px，圆角 24px | 点击跳转问题选择页（需检查配额） |

**交互流程**：
1. 用户打开小程序 → 首页加载，展示品牌区 + 今日运势 + 开始占卜按钮
2. 点击"开始占卜" → 检查配额：
   - 有配额 → 进入问题选择页
   - 无配额 → 弹出付费引导弹窗
3. 点击今日运势卡片 → 进入对应牌义详情
4. 点击快捷分类 → 直接进入问题选择页并预选该分类

**状态变化**：
- 默认状态：完整展示所有元素
- 加载状态：骨架屏占位（品牌区灰块 + 卡片灰块 + 按钮灰块）
- 新用户：今日运势展示"抽一张牌，开启今日运势"引导文案
- 次数用尽：次数提示条变红，显示"今日免费次数已用完"

### 页面 2：引导页（/pages/onboarding/index）

**用途**：向新用户介绍产品核心功能和价值主张
**入口**：首次登录完成后自动进入
**出口**：免责协议页（首次）/ 首页（跳过）

**页面结构（ASCII 线框图）**：

```
┌──────────────────────────────┐
│ ▓▓▓▓ 状态栏 ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │

│                              │
│         [ 跳过 > ]           │  <- 右上角跳过按钮
│                              │
│                              │
│      ┌──────────────┐        │
│      │              │        │
│      │   插画区域    │        │  <- 引导插画
│      │   240x240px  │        │     第1页：选牌手
│      │              │        │     第2页：翻牌面
│      └──────────────┘        │     第3页：看解读

│                              │

│                              │
│                              │
│                              │
│        ● ○ ○                 │  <- 页码指示器

│                              │
│                              │
│  ┌────────────────────────┐  │

**三页内容**：

| 页码 | 插画主题 | 标题 | 描述 |
|------|----------|------|------|
| 第 1 页 | 用户伸手选牌 | 遇见你的塔罗师 | 随时随地，抽一张牌，AI 为你解读当下的困惑 |
| 第 2 页 | 牌面翻转露出 | 沉浸式体验 | 手势洗牌、翻牌动画，感受命运的仪式感 |
| 第 3 页 | AI 文字浮现 | 专业 AI 解读 | 基于占星逻辑的深度解读，温柔有力量 |

**元素说明**：

| 元素 | 类型 | 尺寸/位置 | 交互说明 |
|------|------|-----------|----------|
| 跳过按钮 | 文字按钮 | 右上角，padding 16px | 点击直接跳到免责协议/首页 |
| 插画区域 | 图片 | 240 x 240px，水平居中 | 3 张插画跟随手势切换 |
| 标题 | 文本 | H1，居中 | 跟随页面切换 |
| 描述 | 文本 | Body，居中，最多 2 行 | 跟随页面切换 |
| 页码指示器 | 圆点 | 3 个 8px 圆点，间距 8px | 当前页金色，其余灰色 |
| 下一步按钮 | 主按钮 | 全宽-40px x 48px | 滑动/点击切换；最后一页文字变"开始使用" |

**交互流程**：
1. 新用户登录后自动进入引导页第 1 页
2. 左滑手势或点击"下一步"切换到下一页
3. 第 3 页点击"开始使用" → 进入免责协议页
4. 点击"跳过" → 直接进入免责协议页

**动效说明**：
- 页面切换：水平滑动，0.3s ease-out
- 插画切换：跟随手势，带弹性回弹
- 指示器：当前点放大 1.2x + 颜色渐变 0.2s

**页面结构（ASCII 线框图）**：

```

├──────────────────────────────┤

│                              │

**元素说明**：

| 元素 | 类型 | 尺寸/位置 | 交互说明 |
|------|------|-----------|----------|
| 返回按钮 | 图标按钮 | 导航栏左侧 44x44px | 返回首页（二次确认弹窗） |
| 进度指示 | 文本+圆点 | 导航栏右侧 | "1/3 ●○○"表示当前步骤 |
| 分类按钮 | 图标+文字 | 80x80px，圆角 12px，3+2 排列 | 点击选中，展开对应预设问题 |
| 预设问题卡片 | 单选卡片 | 全宽-40px x 48px | 点击选中，互斥；选中显示金色左边框 |
| 自定义输入框 | 多行文本框 | 全宽-40px x 80px | 最多 100 字，实时字数统计 |
| 字数计数器 | 文本 | 输入框右下 | 实时更新；超出变红 |
| 下一步按钮 | 主按钮 | 底部固定，全宽-40px x 48px | 选中问题后才可点击，跳转牌阵选择 |

**交互流程**：
1. 页面加载，默认无分类选中
2. 点击分类按钮 → 该分类高亮，展开 3 个预设问题
3. 点击预设问题或输入自定义问题 → "下一步"按钮激活
4. 点击"下一步" → 进入牌阵选择页
5. 自定义输入和预设问题互斥：选预设清空输入框，输入文字则取消预设选中

**状态变化**：
- 默认：分类按钮未选中，预设问题隐藏，下一步按钮置灰
- 分类已选：该分类金色边框，预设问题展开
- 问题已选：下一步按钮激活（金色渐变）
- 敏感词命中：输入框红色边框 + 下方提示"请调整问题内容"
- 字数超限：计数器变红，输入截断

**元素说明**：

## 附录 C：组件复用清单

| 组件名 | 用途 | 使用页面 |
|--------|------|----------|
| `NavBar` | 自定义导航栏（返回+标题） | 所有子页面 |
| `TabBar` | 底部标签栏 | 首页、牌义库、我的 |
| `PrimaryButton` | 金色渐变主按钮 | 多个页面 |
| `SecondaryButton` | 边框次要按钮 | 多个页面 |
| `CardContainer` | 半透明圆角卡片 | 套餐、运势、配额等 |
| `DisclaimerText` | 免责声明小字条 | 解读结果、付费页 |
| `LoadingSpinner` | 星形旋转加载指示 | Loading 页、各请求中 |
| `EmptyState` | 空状态插画+文案 | 历史记录、牌义库 |
| `ErrorState` | 错误状态插画+重试 | 全局错误兜底 |
| `TarotCard` | 塔罗牌组件（正/背/大小） | 抽牌、结果、历史 |
| `QuoteCarousel` | 名言/诗句轮播 | Loading 页 |
| `PackageCard` | 套餐卡片 | 付费页、付费弹窗 |
| `DisclaimerModal` | 免责协议弹窗 | 首次使用 |
| `PaymentResultModal` | 支付结果弹窗 | 支付完成后 |

## 附录 D：动效汇总

| 页面 | 动效名称 | 类型 | 时长 | 缓动曲线 | 触发条件 |
|------|----------|------|------|----------|----------|
| 引导页 | 页面滑动 | translateX | 0.3s | ease-out | 手势/按钮 |
| 洗牌页 | 牌面交错 | translate+rotate | 0.3s/组 | ease-in-out | 手势滑动 |
| 洗牌页 | 选牌飞出 | translate+scale | 0.5s | cubic-bezier(0.34,1.56,0.64,1) | 点击牌面 |
| 翻牌页 | 牌面翻转 | rotateY 180° | 0.6s | ease-out | 点击牌面 |
| 翻牌页 | 信息卡片上滑 | translateY | 0.3s | ease-out | 翻牌完成 |
| 解读页 | 牌面入场 | translateY+scale | 0.4s | ease-out | 页面进入 |
| 解读页 | 文字逐字 | opacity | 30ms/字 | - | AI 流式返回 |
| 解读页 | 按钮淡入 | opacity | 0.3s | ease-out | 解读完成 |
| Loading | 星形旋转 | rotate 360° | 1.2s | linear | 持续 |
| Loading | 诗句切换 | opacity | 0.3s | ease-out | 每 3 秒 |
| 支付成功 | 图标弹跳 | scale | 0.4s | cubic-bezier(0.34,1.56,0.64,1) | 页面进入 |
| 支付失败 | 图标抖动 | translateX | 0.6s | ease-out | 页面进入 |
| 弹窗类 | 弹窗出现 | opacity+translateY | 0.25s | ease-out | 触发弹窗 |
